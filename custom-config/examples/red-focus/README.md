# Red Focus Theme

A bold, red-themed configuration for focused productivity tracking.

## Features

- Red/rose color scheme for energy and focus
- Productivity-focused special day activities (meditation, planning)
- Motivational quotes for staying on track

## Usage

Copy `app-settings.json` to your `custom-config/` directory:

```bash
cp custom-config/examples/red-focus/app-settings.json custom-config/
```
