# Green Learning Theme

A calm, green-themed configuration for learning and study tracking.

## Features

- Green color scheme with emerald accents
- Learning-focused special day activities (reading, note review)
- Custom quotes for motivation

## Usage

Copy `app-settings.json` to your `custom-config/` directory:

```bash
cp custom-config/examples/green-learning/app-settings.json custom-config/
```
